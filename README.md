# Optimus HeadCAD
Custom CAD of G1 Optimus Prime's Head!
I've never worked with CAD before; so I was looking for a design that's nice but not overly complex, and can be modelled with boxes and curves. That's when I realized that Optimus Prime's Head is a pretty good fit! He's also my childhood hero so I was really excited and happy to model him in CAD! Decided to work with AUTODESK Fusion with a student license. I'm experienced with blender; and it was kind of annoying at first, but soon it actually turned out to be quite fun (:

Since this is a decorative print, any material can be used, like PLA, ABS, PETG. Consequently; low infill percentages like 5% - 15%% and 2-3 wall loops should be just fine too.
